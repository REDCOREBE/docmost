# Tasks V2 — native UX + custom properties

## V1 vs V2

| | V1 | V2 |
|--|----|----|
| Scope | Parallel Tasks module | Same architecture |
| Global `/tasks` | Forced `assignee=me` | Tabs **Tout / Mes tâches / En retard** (default Tout) |
| Kanban | Basic columns/cards | Native-like styling (independent CSS) |
| Detail | Generic Mantine Modal | `TaskDetailDrawer` property-row layout |
| Custom fields | None | `task_properties*` space-scoped |
| Storage for builtins | `task_items` / `task_assignees` | **Unchanged** (not migrated to EAV) |
| EE / `base_*` | Forbidden | Still forbidden |

## Invariants (unchanged)

- No imports from `apps/client/src/ee/base/**`
- No `base_*` tables
- No CASL / SpaceService / pages / spaces / users schema changes
- Removable by dropping `task_*` + removing module wiring

## New tables

See `DATABASE.md` — `task_properties`, `task_property_options`, `task_property_values`.

## API (additive)

- `POST /tasks/properties` — list by `spaceId`
- `POST /tasks/properties/create|update|delete`
- `POST /tasks/properties/value` — upsert/clear value

ACL: Read Page / Edit Page / Manage Settings (existing Space CASL subjects only).

Visual reference may be observed from Docmost Bases Kanban / Row detail.
