## Invariants (data plane)

- No `base_*` tables / no `BaseService` from Tasks
- No CASL / SpaceService / pages / spaces / users schema changes
- Removable by dropping `task_*` + removing module wiring
- Synthetic `pageId` never used to call Base APIs
- Network: **0 `/api/bases*`** from Space/Global Tasks surfaces

## Architecture (client)

```
pages/tasks/* → TasksNativeShell (+ BaseDataPortsProvider)
                 ├─ BaseTable
                 ├─ BaseKanban / KanbanColumn (Pragmatic DnD)

                      ↑
           TasksNativeUiAdapter + Task API (/api/tasks*)
```
