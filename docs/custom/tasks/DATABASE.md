# Database

## Tables

### task_items

| Column | Type | Notes |
|--------|------|-------|
| id | uuid PK | `gen_uuid_v7()` |
| workspace_id | uuid FK workspaces CASCADE | |
| space_id | uuid FK spaces CASCADE | |
| title | varchar NOT NULL | |
| description | text NULL | |
| status | varchar | CHECK `todo\|in_progress\|done` |
| priority | varchar | DEFAULT `none`; CHECK set |
| progress | smallint | DEFAULT 0; CHECK 0..100 |
| due_date | timestamptz NULL | |
| created_by_id | uuid FK users SET NULL | |
| created_at / updated_at | timestamptz | |
| completed_at | timestamptz NULL | set when status → done |
| linked_page_id | uuid FK pages SET NULL | optional |

Indexes:

- `idx_task_items_workspace_space_status (workspace_id, space_id, status)`
- `idx_task_items_workspace_due` partial `WHERE due_date IS NOT NULL`
- `idx_task_items_linked_page` partial `WHERE linked_page_id IS NOT NULL`

### task_assignees

PK `(task_id, user_id)`. Both FKs CASCADE. Index `(user_id, task_id)`.

### task_views

- `space_id` nullable, `owner_user_id` nullable
- `type` CHECK `table|kanban`
- `config` jsonb, `position` varchar

## Soft vs hard delete

Tasks use **hard delete**. Spaces hard-delete → CASCADE removes tasks. Pages soft-delete → linked_page becomes inaccessible for hydration; FK SET NULL only on hard page delete.
