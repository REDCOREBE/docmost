# Database

## Tables (V1)

### task_items

| Column | Type | Notes |
|--------|------|-------|
| id | uuid PK | `gen_uuid_v7()` |
| workspace_id | uuid FK workspaces CASCADE | |
| space_id | uuid FK spaces CASCADE | |
| title | varchar NOT NULL | |
| description | text NULL | |
| status | varchar | CHECK `todo\|in_progress\|done` |
| priority | varchar | DEFAULT `none`; CHECK set |
| progress | smallint | DEFAULT 0; CHECK 0..100 |
| due_date | timestamptz NULL | |
| created_by_id | uuid FK users SET NULL | |
| created_at / updated_at | timestamptz | |
| completed_at | timestamptz NULL | set when status → done |
| linked_page_id | uuid FK pages SET NULL | optional |

Indexes:

- `idx_task_items_workspace_space_status (workspace_id, space_id, status)`
- `idx_task_items_workspace_due` partial `WHERE due_date IS NOT NULL`
- `idx_task_items_linked_page` partial `WHERE linked_page_id IS NOT NULL`

### task_assignees

PK `(task_id, user_id)`. Both FKs CASCADE. Index `(user_id, task_id)`.

### task_views

- `space_id` nullable, `owner_user_id` nullable
- `type` CHECK `table|kanban`
- `config` jsonb (`visibleColumnIds`, `visiblePropertyIds`, …), `position` varchar

## Tables (V2 — custom properties)

System fields stay on `task_items` / `task_assignees`. **No `is_system` column.**

### task_properties

| Column | Type | Notes |
|--------|------|-------|
| id | uuid PK | `gen_uuid_v7()` |
| workspace_id | uuid FK CASCADE | |
| space_id | uuid FK CASCADE NOT NULL | **space-scoped only** |
| name | varchar NOT NULL | |
| type | varchar | CHECK text/long_text/number/select/multi_select/date/person/page |
| config | jsonb | default `{}` |
| position | varchar | fractional index |
| created_at / updated_at | timestamptz | |

Indexes:

- `idx_task_properties_workspace_space (workspace_id, space_id)`
- unique `idx_task_properties_space_name_ci (space_id, lower(trim(name)))`

### task_property_options

| Column | Notes |
|--------|-------|
| id | uuid PK |
| property_id | FK CASCADE → task_properties |
| name | varchar |
| color | varchar nullable |
| position | varchar |

Index on `property_id`.

### task_property_values

| Column | Notes |
|--------|-------|
| task_id | FK CASCADE → task_items |
| property_id | FK CASCADE → task_properties |
| value_text / value_number / value_timestamptz / value_json | typed nullables |
| PK | `(task_id, property_id)` |

Indexes on `task_id`, `property_id`.

## Soft vs hard delete

Tasks use **hard delete**. Spaces hard-delete → CASCADE removes tasks + properties. Pages soft-delete → linked_page becomes inaccessible for hydration; FK SET NULL only on hard page delete.
